# Career Guidance AI Application

This is a Flask-based web application that provides career guidance using the Groq AI API.

## Features

- Career path suggestions
- Resume/CV feedback
- Job market insights
- College/major advice
- Interview preparation tips

## How to Run

1.  **Clone the repository:**
    ```bash
    git clone https://github.com/Neelshah1810/Career-Guidance-AI-Application.git
    ```
2.  **Install the dependencies:**
    ```bash
    pip install -r requirements.txt
    ```
3.  **Create a `.env` file** and add your Groq API key:
    ```
    GROQ_API_KEY=your_groq_api_key
    ```
4.  **Run the application:**
    ```bash
    python main.py
    ```
5.  Open your browser and navigate to `http://127.0.0.1:8001`.
